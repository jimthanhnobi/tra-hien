# Plans

Supporting task records for existing roadmap IDs, one `<task>-implementation.md` per `P*-*` task, written from [task-template.md](task-template.md). The only backlog is `docs/spec/07-roadmap.md`: do not create `tasks.md`, `implementation-plan.md` or any second task list. Cross-task readiness lives in [task-readiness.md](task-readiness.md); shared design notes (for example [p1-inventory-architecture.md](p1-inventory-architecture.md)) cover several existing tasks.
