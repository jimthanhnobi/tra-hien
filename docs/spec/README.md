# Trà Hiên V2 - Authoritative specification directory

**Paste your original Markdown specs here**, including nested folders and relative links.

Example:
- `docs/spec/product/requirements.md`
- `docs/spec/catalog/data-model.md`
- `docs/spec/marketing/seo.md`

The names above are illustrations only, NOT real requirements or a proposed architecture.

Rules:
1. Original Markdown files are the source of truth; preserve original meaning.
2. Do not edit original requirements automatically during an audit.
3. Record inconsistencies separately in `docs/analysis/spec-gaps.md`.
4. Specs may contain trade secrets or customer data. THIS REPOSITORY IS PUBLIC: remove sensitive data or make the repository private before committing.
5. When specs change, rerun audit, traceability and impact assessment.
